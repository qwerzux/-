# Help Desk

## Описание проекта

Help Desk — это консольная информационная система для учёта и обработки обращений пользователей в службу поддержки.

Система позволяет создавать обращения, назначать операторов, изменять статус обращения и добавлять ответы пользователям.

## Цель проекта

Автоматизация процесса обработки обращений пользователей в службу поддержки.

## Основные возможности

- добавление пользователей;
- просмотр списка пользователей;
- удаление пользователей;
- добавление операторов поддержки;
- просмотр списка операторов;
- удаление операторов;
- создание обращений;
- назначение оператора на обращение;
- изменение статуса обращения;
- удаление обращения;
- добавление ответа на обращение;
- просмотр ответов по обращению.
